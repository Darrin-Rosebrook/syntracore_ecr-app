# Onboard eCR

**Onboard eCR** is a modern onboarding and collaboration platform designed to streamline electronic case reporting (eCR) across the U.S. public health ecosystem. It enables Health Care Organizations (HCOs) to efficiently enroll and onboard to submit eICR data to the correct Public Health Authority (PHA).

## 🔍 Overview

Onboard eCR provides:

- **Self-service onboarding** for HCOs
- **Role-based access control (RBAC)** for HCOs, vendors, PHAs, and federal partners
- **FHIR and CDA eICR validation** tools
- **Jurisdiction routing** using NPI, CLIA, and location metadata
- Real-time tracking across onboarding phases
- Integrated collaboration for:
  - State PHAs
  - EHR/LIMS Vendors
  - APHL / AIMS
  - CDC

## 🚀 Features

- Custom enrollment workflows
- Legal readiness and intake forms
- eICR message validation engine
- PHA reviewer dashboards
- Multi-tenancy support (multi-state onboarding)
- Family-of-organizations login support (health systems)

## 🏛️ Federal Alignment

The platform integrates with and supports oversight from:
- **CDC** — Federal leadership for eCR adoption and policy
- **APHL** — Operational infrastructure via AIMS and metadata services

## ⚙️ Technologies Used

- Firebase (Firestore, Auth, Hosting)
- React + Tailwind UI (ShadCN)
- TypeScript
- Node.js
- GitHub Actions (optional for CI/CD)
